# Задания: записи и фильтрация

Небольшой учебный проект: восемь задач на описание объектов и отбор записей по условию. Для каждой задачи есть версия на C++ и Python.

## Задачи

| № | Тема | Условие отбора |
|---|---|---|
| 01 | Футболисты | Более 50 матчей |
| 02 | Манекенщицы | Самая молодая участница |
| 03 | Международные компании | Более 10 000 сотрудников |
| 04 | Зоопарки | Есть уссурийские тигры |
| 05 | Мультфильмы | Компания Walt Disney |
| 06 | Баскетболисты | Более 150 очков |
| 07 | Области | Население меньше 1 млн |
| 08 | Мотоциклы | Марка HarleyDavidson |

## Запуск

Запустить Python-задачу:

```powershell
python python/task_01.py
```

Скомпилировать и запустить C++-задачу:

```powershell
g++ -std=c++17 cpp/task_01.cpp -o task_01.exe
./task_01.exe
```

Вместо `01` укажите номер нужной задачи.

## Структура

- `assignment.md` — формулировки заданий.
- `python/` — решения на Python.
- `cpp/` — решения на C++.
- `materials/` — исходные учебные материалы.

Примеры записей в программах вымышлены и используются только для демонстрации фильтрации.
